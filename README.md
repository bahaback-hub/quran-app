# 📖 القرآن الكريم - تطبيق ويب تفاعلي

> تطبيق ويب احترافي للقرآن الكريم يعمل على جميع الأجهزة، قابل للتثبيت كتطبيق (PWA)، ويعمل أوفلاين.

[🌐 افتح التطبيق مباشرة](https://bahaback-hub.github.io/quran-app/)

## ✨ المميزات

- 🎵 **​تلاوة كاملة​** بأصوات 8 قرّاء مشهورين (العفاسي، عبد الباسط، السديس، الحصري، المنشاوي، أيوب، الحذيفي، الشاطري)
- 🔍 **​بحث ذكي​** في القرآن كاملًا مع تظليل الكلمات المطابقة
- 📜 **5 تفاسير​** معتمدة (الطبري، ابن كثير، السعدي، البغوي، القرطبي)
- 🕋 **​وضع الحفظ​** بتمويه الآيات تدريجيًا
- 🔁 **​التكرار المتقدّم​** لنطاق آيات محدّد
- 🌙 **​الوضع الليلي​** مع تأثيرات بصرية
- 📱 **​تجاوب كامل​** للموبايل والتابلت
- 🎵 **​مشغّل عائم سفلي​** قابل للإخفاء
- ⌨️ **​اختصارات لوحة المفاتيح​** للاستخدام السريع
- 👆 **​إيماءات اللمس​** للتنقّل بين السور
- 📲 **​قابل للتثبيت​** على سطح المكتب والموبايل
- 🔌 **​يعمل أوفلاين​** بعد أول تحميل

## 📲 التثبيت

### على الموبايل:
1. افتح الرابط في Chrome (Android) أو Safari (iOS)
2. اضغط قائمة المتصفّح
3. اختر "إضافة إلى الشاشة الرئيسية"

### على الحاسوب:
1. افتح الرابط في Chrome أو Edge
2. اضغط أيقونة التثبيت في شريط العنوان
3. اضغط "تثبيت"

## ⌨️ اختصارات لوحة المفاتيح

| المفتاح | الوظيفة |
|---------|---------|
| `Space` | تشغيل / إيقاف |
| `←` `→` | الآية السابقة / التالية |
| `S` `D` | السورة السابقة / التالية |
| `H` | تفعيل/إيقاف وضع الحفظ |
| `T` | فتح/إغلاق التفسير |
| `R` | فتح نافذة التكرار |

## 🛠️ التقنيات المستخدمة

- HTML5 + CSS3 + Vanilla JavaScript
- PWA (Progressive Web App)
- Service Worker للعمل أوفلاين
- LRU Cache لتحسين الأداء
- AlQuran.cloud API للنصوص والصوت
- Tafsir API (spa5k) للتفاسير
