# 📖 القرآن الكريم — تطبيق ويب تفاعلي

تطبيق ويب عربي للقرآن الكريم: قراءة، تلاوة، مصحف، تفسير، بحث، مواقيت صلاة، وأذكار. يعمل على الجوال والحاسوب، قابل للتثبيت كتطبيق (PWA)، ويدعم العمل دون اتصال بعد أول زيارة.

**[افتح التطبيق مباشرة](https://bahaback-hub.github.io/quran-app/)**

---

## ✨ المميزات

### القرآن والتلاوة
- قراءة **114 سورة** بنص عثماني مع تمييز الآية الحالية
- **أكثر من 25 قارئاً** (AlQuran.cloud + mp3quran.net): العفاسي، عبد الباسط، السديس، الحصري، المنشاوي، أيوب، الشاطري، الغامدي، الشريم، القطامي، وغيرهم
- **وضع السورة** و**وضع المصحف** (604 صفحة) مع تنقّل بالصفحات والأجزاء
- **وضع الحفظ** — إخفاء الآيات تدريجياً حتى تُكشف عند المرور عليها
- **التكرار المتقدّم** — تكرار نطاق آيات بعدد مرات محدّد
- سرعة تشغيل قابلة للتعديل (0.5× — 2×)
- مشغّل سفلي قابل للطي مع حفظ آخر موضع تلقائياً

### البحث والتفسير
- **بحث دقيق** في القرآن كاملاً مع تظليل يحترم التشكيل
- **بحث بالجذر** عبر قاعدة جذور مدمجة
- **إكمال تلقائي** للكلمات، **بحث صوتي**، و**لوحة مفاتيح عربية** على الشاشة
- **6 تفاسير**: الميسّر، الطبري، ابن كثير، السعدي، البغوي، القرطبي
- **ترجمات المعاني**: إنجليزي (Sahih International، Pickthall، Yusuf Ali)، فرنسي، أردو
- نافذة تفصيلية للآية (تشغيل، نسخ، مشاركة، تفسير)

### العبادة والمواقيت
- **مواقيت الصلاة** حسب المدينة وطريقة الحساب (أم القرى، الهيئة المصرية، رابطة العالم الإسلامي، وغيرها)
- **تنبيه الأذان** (صوت الشيخ ناصر القطامي) مع إمكانية تعطيل أذان الفجر
- **الأذكار** — تبويبات جاهزة، عدّاد تكرار، تذكيرات، وإضافة أذكار مخصّصة
- **أسرار السور** — فوائد وتوجيهات مختصرة لكل سورة

### التجربة والتخصيص
- **PWA** — تثبيت على الشاشة الرئيسية أو سطح المكتب
- **عمل أوفلاين** — تخزين النص الكامل في IndexedDB + Service Worker للصوت والمصحف
- الوضع الليلي، خلفيات متعددة، حجم خط قابل للتعديل
- **عربي / English** في واجهة التطبيق
- مفضلة، علامة مرجعية (نقرة للحفظ، نقرتان للانتقال)
- مشاركة عبر الواتساب، تيليجرام، الحافظة، أو مشاركة النظام
- وضع عرض تقديمي للشاشات الكبيرة
- تصميم متجاوب مع دعم RTL وإمكانية وصول (اختصار تخطّي المحتوى، تقليل الحركة)

## 📲 التثبيت كتطبيق (PWA)

### على الموبايل
1. افتح [رابط التطبيق](https://bahaback-hub.github.io/quran-app/) في **Chrome** (أندرويد) أو **Safari** (iOS).
2. من قائمة المتصفّح اختر **إضافة إلى الشاشة الرئيسية**.

### على الحاسوب
1. افتح الرابط في **Chrome** أو **Edge**.
2. اضغط أيقونة التثبيت في شريط العنوان ثم **تثبيت**.

> بعد أول تحميل كامل، يعمل القرآن والبحث والمواقيت المحفوظة دون اتصال. التلاوة والمصحف يُخزَّنان تدريجياً في الذاكرة المؤقتة.

## ⌨️ اختصارات لوحة المفاتيح

| المفتاح | الوظيفة |
|---------|---------|
| `Space` | تشغيل / إيقاف |
| `←` `→` | الآية السابقة / التالية |
| `S` `D` | السورة السابقة / التالية |
| `H` | وضع الحفظ |
| `T` | فتح / إغلاق التفسير |
| `R` | التكرار |
| `M` | التبديل بين السورة والمصحف |
| `B` | حفظ علامة مرجعية |
| `G` | الانتقال إلى العلامة |
| `F` | إضافة / إزالة من المفضلة |
| `N` | الوضع الليلي |
| `P` | وضع العرض التقديمي |
| `+` `-` `0` | تكبير / تصغير / إعادة حجم الخط |
| `Ctrl+F` | التركيز على مربع البحث |
| `Esc` | إغلاق اللوحات والقوائم |

> الاختصارات لا تعمل أثناء الكتابة في حقول الإدخال.

## 🛠️ التطوير المحلي

### المتطلبات
- [Node.js](https://nodejs.org/) 20 أو أحدث (يُستخدم 22 في CI)

### التشغيل

```bash
git clone https://github.com/bahaback-hub/quran-app.git
cd quran-app
npm ci
npm run dev
```

يفتح خادم التطوير على `http://localhost:3000`.

### أوامر أخرى

| الأمر | الوصف |
|-------|--------|
| `npm run build` | بناء الإنتاج إلى مجلد `dist/` |
| `npm run preview` | معاينة نسخة الإنتاج محلياً |
| `npm test` | تشغيل اختبارات Vitest |
| `npm run typecheck` | فحص الأنواع (TypeScript + JSDoc) |

### هيكل المشروع (مختصر)

```
quran-app/
├── index.html          # نقطة الدخول
├── styles.css          # التنسيقات (RTL، الوضع الليلي)
├── src/                # منطق التطبيق (وحدات ES)
│   ├── app.js          # التهيئة وربط الأحداث
│   ├── audio.js        # التلاوة والحفظ والتكرار
│   ├── search.js       # البحث والصوت ولوحة المفاتيح
│   ├── mushaf.js       # عرض المصحف
│   ├── prayer.js       # المواقيت والأذان
│   ├── tafsir.js       # التفسير
│   ├── adhkar.js       # الأذكار
│   └── __tests__/      # الاختبارات
├── public/pages/       # صور صفحات المصحف
├── vite.config.js      # Vite + PWA (Workbox)
└── service-worker.js   # Service Worker إضافي للتخزين المؤقت
```

لتفاصيل الاتفاقيات والبنية، راجع [`AGENTS.md`](AGENTS.md).

### النشر

يُنشر التطبيق تلقائياً على **GitHub Pages** عند الدفع إلى `main` عبر GitHub Actions (بعد تفعيل Pages من مصدر **GitHub Actions** في إعدادات المستودع).
